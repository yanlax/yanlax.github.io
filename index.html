Десктопное приложение для диагностики ноутбуков

Инженер проходит проверки по сценарию, приложение собирает данные и формирует отчёт.

Приложение для Windows проверяет батарею, диск, клавиатуру, матрицу, тачпад и датчики, а также создаёт нагрузку, чтобы поймать перегрев. Результаты собираются в отчёт, который экспортируется в PDF, Excel или TXT. Я сделал приложение целиком: UI/UX дизайн, фронтенд и бэкенд.
